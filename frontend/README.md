# AetherVesting Frontend

AetherVesting is a Next-Generation Institutional Web3 Token Vesting & Locked Capital Management DApp.

## Overview
- **Smart Contract Integration**: Interacts directly with `TokenVesting.sol` deployed on Ethereum Sepolia.
- **Wallet Connectivity**: RainbowKit and Wagmi v2 supporting MetaMask, WalletConnect, and Coinbase Wallet.
- **Capital Analytics**: Real-time linear vesting curves, cliff milestone projections, and automated claim execution.

## Getting Started
First, install dependencies and run the development server:
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
